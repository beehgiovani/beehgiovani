# Bruno Giovani

Desenvolvedor com foco em **Python, dados e GIS**, além de experiência prática em **Android/Kotlin**, automação e integração de sistemas.

Construo ferramentas para transformar dados dispersos em fluxos reproduzíveis, mapas consultáveis e aplicações úteis. Os projetos abaixo são apresentados com o estágio real de maturidade — produto, protótipo ou referência técnica — sem confundir demonstração com operação comercial validada.

## Foco atual

- pipelines de coleta, validação e organização de dados;
- geoprocessamento e interfaces GIS;
- automações responsáveis e reexecutáveis;
- aplicativos Android com Kotlin e Jetpack Compose;
- APIs e integrações necessárias para sustentar esses produtos.
